2. What MESH Is

MESH is an encrypted peer-to-peer messaging application built on the Stellar blockchain and IPFS (InterPlanetary File System). MESH provides:

  • End-to-end encrypted messaging using NaCl box encryption
  • Blockchain-based message delivery via the Stellar network
  • Decentralized message storage via IPFS/Pinata
  • A username registry on our relay server for contact discovery
  • Optional XLM (Stellar Lumens) transfers between users

3. No Account Required — Your Keys Are Your Identity
